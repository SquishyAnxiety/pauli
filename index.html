API usage

Simply send a POST request to /api with the desired input string in the content field to receive the converted string in result.

See example below:

curl -X POST -H "Content-Type: application/json" \
  -d '{ "content": "monster energy" }' \
  /api

{ "result": "{{ example }}" }
